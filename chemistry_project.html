Project "Chemistry"

Project "Chemistry" is a 2D pixel art game where you control a fantasy character that can harvest molecules from natural sources using her wand.
During the day you explore the world to find molecules and discover new reactions. You use the Reactor to create new molecules and materials that you can use to build your base and to cast powerful spells. You must defend the Reactor at night.

The game is being developed with a custom C# 2D engine.
